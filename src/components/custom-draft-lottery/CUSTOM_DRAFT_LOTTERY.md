# Custom Draft Lottery 

## Installed Features
1. Set Custom Draft Order (before lottery takes place), with traded, and currently owned picks
2. Create 1001 Lottery combos, after draft order was set. View said lotto combos, and have the ability to download combos in csv or excel?
3. Draw lottery combos
   1. draws 1 by 1, as the NHL does
   2. you can set the countdown timer for suspense purposes, presets are  0.1, 1, 3, 5, 10 seconds
   3. See how odds change in real time, including the balls needed to win that respective lottery
   4. Forces redraw if invalid
4. View Draft Order
   1. Updates live after each lottery drawing
   2. You can click button to export draft order to image
